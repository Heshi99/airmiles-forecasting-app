✈️ Air Miles Forecasting Dashboard
This project is an interactive time series forecasting dashboard built with Streamlit. It predicts future air travel demand using the Holt-Winters Exponential Smoothing method. Users can select a forecast horizon (1–36 months) and visualize historical trends, seasonal patterns, and forecasted values in real-time.

🔍 Features
📊 Forecast monthly air miles for up to 3 years

🛠️ Adjust forecast horizon dynamically with an intuitive slider

📉 Visualize historical data alongside predicted trends

🧮 Model evaluation using MAE, RMSE, and MAPE

🚀 Deployed using Streamlit for easy interaction
